# 1\. OBJETIVO

Este documento define o escopo formal do projeto "Cineclube UniFAFIRE", estabelecendo claramente o que está incluso e o que está excluído do trabalho a ser realizado.

# 2\. INCLUSO NO ESCOPO

As seguintes funcionalidades estão INCLUÍDAS no projeto:

- Site institucional para cineclube universitário
- Sistema de avaliação de filmes (notas de 1 a 5 estrelas)
- Sistema de comentários opcionais nos filmes
- Login institucional para acesso restrito
- Histórico completo de filmes exibidos
- Design responsivo (compatível com desktop e mobile)
- Versionamento de código no GitHub
- Deploy contínuo na plataforma Lovable

# 3\. EXCLUÍDO DO ESCOPO

As seguintes funcionalidades estão EXCLUÍDAS do projeto atual:

- Cadastro de novos membros (login feito com email único)
- Streaming próprio de vídeos (apenas informações sobre filmes)
- Aplicativo mobile nativo (somente versão web responsiva)
- Sistema de login de alunos para comprovar presença nas sessões

# 4\. LIMITES DO PROJETO

| **Aspecto**                | **Delimitação**                                          |
| -------------------------- | -------------------------------------------------------- |
